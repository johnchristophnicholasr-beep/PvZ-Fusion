# PvZ Fusion - Android Garden Strategy Game

The repository contains an original, offline-first Android strategy prototype.

## Latest implementation

- Staged offline loading screen with visible progress.
- Playable touch garden board with plants, zombies, projectiles, health bars, waves, and AOE attacks.
- Editable plant, fusion, level, challenge, and achievement data.
- Tutorial, Almanac, Fusion Encyclopedia, Challenges, Achievements, Profile, and Save/Backup screens.
- Three isolated local save slots with atomic writes and validated automatic backups.
- Local Settings screen for sound, music, particles, reduced motion, and difficulty preferences.
- Original vector icon and no required network connection.

Open the project in Android Studio with Android Gradle Plugin 8.1+ and build the `app` module. Before release, add automated tests, original animated art/audio, and complete Puzzle, Survival, and Endless mode rules.
